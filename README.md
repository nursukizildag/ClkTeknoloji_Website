## 🇬🇧 English

### 📌 Project Overview
This project was initially developed as a static website for a real business to design, develop, and deploy a live website from scratch. It has since evolved into a full-stack application featuring a dynamic Admin Panel, Serverless API, and Database integration to manage website content effectively.

### 🚀 What I Did
- Designed and developed the responsive frontend using HTML, CSS, and JavaScript
- Built a secure Admin Panel to dynamically manage website content
- Implemented a serverless backend API using Cloudflare Pages Functions
- Integrated Cloudflare KV for secure Admin authentication
- Configured and connected a Neon Database (Serverless PostgreSQL) for data storage
- Purchased and configured a domain with basic DNS management
- Set up hosting and deployed the website live via Cloudflare Pages

### 🛠 Technologies Used
- **Frontend:** HTML5, CSS3, JavaScript (Vanilla)
- **Backend:** Cloudflare Pages Functions (Serverless)
- **Database:** Neon Database (PostgreSQL)
- **Authentication:** Cloudflare KV
- **Tooling & Deployment:** Cloudflare Pages, Wrangler CLI, Node.js

### 🎯 What I Learned
- Real-world project experience from client requirements to deployment
- Full-stack development with Serverless architecture (Cloudflare Functions)
- Database design and management (PostgreSQL with Neon)
- Implementing secure authentication mechanisms
- Domain & DNS management
- Hosting and deployment process using Wrangler CLI and Cloudflare Pages
